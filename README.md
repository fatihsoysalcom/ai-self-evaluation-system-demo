# AI Self Evaluation System Demo

This example demonstrates a simplified autonomous evaluation system. An 'AI agent' generates a text response based on a topic, and then a separate 'evaluator AI' automatically assesses the quality of that response against predefined criteria, providing a score and feedback without human intervention.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
